# File & Route Map — نقشه فایل و مسیرها

This is the internal map that the restructure was planned from. Read it before moving
any file: every move below lists the dependents that had to be updated in the same
commit.

* Generated: 2026-09-22
* Rule used for every move: **no healthy file is deleted**; a file is either moved
  (with its `require`/URL references fixed) or replaced by a thin compatibility stub
  that keeps the old URL working.

## 3. Route table

`config/routes.php` is now the **single source of truth**. It returns
`['routes' => …, 'aliases' => …, 'patterns' => …]`; `router.php` expands it, and
`.htaccess` sends every request to `router.php`.

Expansion rules (applied by `router.php::jhdRouteTable()`):

* canonical `/x` also answers `/x/` and `/x.php`
* canonical `/x` whose target is `index.php` also answers `/x/index.php`
* a path that already contains a dot (`/sitemap.xml`, `/index.php`, `/php/install.php`)
  stays exact — no extra variants
* aliases answer **as written** (plus a trailing slash) and reuse the canonical entry of
  their target, so an alias never invents a `.php` spelling. That is why `/install`
  reaches the installer while `/install.php` stays 404
* only scripts listed as targets (or matched by a pattern) are reachable — everything
  else is 404

## 4. `$_SERVER` contract between `router.php` and the pages

| Variable | Value | Used by |
|---|---|---|
| `REQUEST_URI` | untouched original request | `currentUrl()`, pagination |
| `SCRIPT_NAME`, `PHP_SELF` | `BASE_PATH . '/' . <script file>` (e.g. `/pages/about.php`, `/admin/users/index.php`) | `basename()`/`dirname()` active-menu logic in `includes/header.php` and `admin/includes/header.php`; role gate regex; `includes/admin-actions.php` confirm form |
| `JHD_ROUTE_PATH` | canonical URL path that matched (e.g. `/about`, `/admin/users`) | `<link rel="canonical">` in `includes/header.php` so internal paths never leak |

## 5. Credentials policy

* Administrator username may default to `admin`; there is no published/default password. Installation and CLI account creation require a unique password of at least 14 characters supplied through a secure form/environment.
* Stored **only** as `password_hash(..., PASSWORD_DEFAULT)`; the plaintext is never
  written to the database, to `config/local.php` or to a log.
* `php/install.php` and `bin/create-admin.php` create the account when missing and
  **reset** the password (plus `auth_version = auth_version + 1`, which invalidates all
  existing sessions) when the account already exists.
