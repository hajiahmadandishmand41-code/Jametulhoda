# قرارداد محتوا ← رابط کاربری (Content → UI Contract)

وضعیت موجودِ تثبیت‌شده برای هر ۸ نوع محتوا. مبنا: `docs/CONTENT_CONTRACT.md` (داده) —
این سند مشخص می‌کند هر داده **کجا و چگونه** نمایش داده می‌شود.
تغییر هر سطر باید تست‌های `route-status` / `http` / link-audit را سبز نگه دارد.

## پوسته سراسری (همه انواع)

- **RTL + فارسی:** `<html lang="fa" dir="rtl">`، فونت وزیرمتن (`assets/fonts/Vazirmatn-*.woff2` با preload).
- **شبکه:** Bootstrap RTL + گرید `row g-4`؛ کارت‌ها `h-100` (هم‌ارتفاع در ردیف).
- **سربرگ:** دکمه همبرگری `#menuToggle` + کشوی کناری `#siteDrawer` (موضوعات درختی، محتوا، دروس حوزه، رسانه، حساب).
- **رنگ تم:** `#163b37` (سبز تیره اسلامی) + طلایی `text-gold` برای آیکن‌ها.
- **تصویر:** همه از `imgUrl()`؛ lazy (`loading="lazy"`)؛ هر کارت placeholder آیکنی دارد (بدون تصویر خراب).
- **تاریخ:** همه با `persianDate()` (شمسی)؛ خلاصه با `excerpt()` (متن فارسی، بدون تگ).
- **موبایل:** گریدها تک‌ستونه می‌شوند (`col-md-*` به‌صورت پیش‌فرض ۱۰۰٪)؛ کشو جایگزین منو؛ پلیرها `w-100`.

## شکاف‌های ثبت‌شده برای مرحله UI/UX (بدون تغییر در این مرحله)

1. **Hero واقعی وجود ندارد** — صفحه اصلی با بنر strip ویژه (اختیاری) شروع می‌شود؛ comment کد به hero اشاره می‌کند ولی سکشنی نیست.
2. **Featured Card متمایز** برای مقاله/خبر/پژوهش/کتاب/ویدیو/صوت وجود ندارد (فقط درس بج «ویژه» و موضوع کارت ویژه دارد).
3. **List Item یکدست** فقط برای صوت در صفحه موضوع وجود دارد؛ جستجو و بقیه فهرست‌ها کارت‌اند.
4. سه خانواده کارت موازی (`article-card` / `news-card` / `content-card`+inline-style کتاب) — یکدست‌سازی در بازطراحی.
5. `pages/post.php` هنوز resolver inline دارد (عمداً دست نخورده ماند چون تست سبزی به آن وابسته است و رفتار یکسان است).

## موبایل (تعهد رفتاری مشترک)

- همه فهرست‌ها در `<768px` تک‌ستونه‌اند، **به‌جز** کتاب (`col-6` دو ستونه) و موضوع ویژه (`col-6` دو ستونه).
- هیچ اسکرول افقی، هیچ متن بریده‌شده بدون `...`، هیچ CTA کوچک‌تر از هدف لمسی.
- کشوی همبرگری تنها ناوبری موبایل است (بدون تب‌بار پایین).
